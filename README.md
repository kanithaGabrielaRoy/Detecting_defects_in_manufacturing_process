# Detecting Defects in Manufacturing Process

## Overview

This project uses deep learning and computer vision techniques to automatically detect defects in manufactured products from industrial images. It aims to improve quality inspection by accurately classifying defective and non-defective products, reducing manual effort and enhancing production efficiency.

## Technologies Used

- Python
- TensorFlow & Keras
- OpenCV
- NumPy
- Matplotlib

## Models Implemented

- VGG16
- ResNet50
- ResNet101
- MobileNet
- Inception

## Dataset

Industrial casting defect image dataset containing defective and non-defective product images.

## Results

The models are trained and evaluated using standard performance metrics to identify the most effective architecture for manufacturing defect detection.
